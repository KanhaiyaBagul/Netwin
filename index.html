Important Evaluation Reminders for Hiring Tests:

  • Separate logic from screen: Put core rules in standalone functions/classes before touching the DOM.
  • Order of checks matters: Always test for empty/invalid inputs first before checking resource availability.
  • Touching intervals are NOT overlaps: startA < endB && endA > startB correctly handles exact touching times like 13:00.
  • No external frameworks: Everything is written in clean, readable, plain Vanilla JavaScript and CSS.
