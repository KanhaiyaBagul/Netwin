# Simple Management Starter

A simple, direct template for CRUD and record management problems asked in campus tests.

## Files
- `index.html` - Basic form, filter bar, and data table.
- `style.css` - Simple, clean styles without any framework.
- `script.js` - Array storage, add/delete/status toggle functions, search/filter, and localStorage.

## How to use for a new problem:
1. Change the input fields in `index.html` (e.g. change "Category" to "Doctor" or "Room Type").
2. Update the properties in `newRecord` in `script.js`.
3. Add any specific conflict or validation rule inside `handleAddRecord()`.
4. Update the table `<th>` and `<td>` columns to match your fields.
